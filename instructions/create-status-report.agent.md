# Create Status Report

Generate a weekly status report in Markdown.

Requirements:
- Use Markdown format only.
- Include these sections in order:
  - Accomplishments
  - Blockers
  - Next Week
- Use bullet points only.
- Keep the total output to a maximum of 20 lines.
- Use a professional tone.
- Do not include fluff words or filler language.
- Keep content concise, factual, and actionable.

Output format:
```markdown
## Accomplishments
- ...
- ...

## Blockers
- ...
- ...

## Next Week
- ...
- ...
```

Rules:
- Do not add headings beyond the three required sections.
- Do not use paragraphs or narrative text.
- Do not include emojis, marketing language, or generic filler.
- Focus on completed work, risks, and planned actions.
